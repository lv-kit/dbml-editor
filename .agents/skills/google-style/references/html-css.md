# HTML / CSS — Google HTML/CSS Style Guide

適用範囲: `.html` `.css` `.scss` ファイルのみ。**JSX/TSX 内のマークアップ、Tailwind 等のユーティリティクラス、CSS-in-JS には適用しない**（それらは `typescript.md` の管轄）。インデント幅・行長・クォート種別は prettier / stylelint の設定に従い、ここでは扱わない。

## 共通

- ファイルは UTF-8（BOM なし）で保存する
- 要素名・属性名・属性値・セレクタ・プロパティ名はすべて小文字で書く
- 行末に空白を残さない
- 「何をしているか」ではなく「なぜそうしたか」をコメントに書く。ハックや回避策には必ず理由を残す
- TODO は `<!-- TODO: <文脈> - <やること> -->` / `/* TODO: ... */`

## HTML

- 構造・表現・振る舞いを分離する。スタイルは CSS に、挙動は JS に置く。`style` 属性と `onclick` 属性を書かない
- 意味に合ったタグを使う。クリックできるものは `<button>` か `<a>` で、`<div onclick>` にしない
- 見出しは `<h1>`〜`<h6>` で階層を飛ばさずに使う。見た目のために見出しレベルを選ばない
- `<img>` には `alt` を必ず書く。装飾目的なら `alt=""` にする
- `type` 属性を省略する（`<script>` `<style>` `<link rel="stylesheet">`）
- 妥当な HTML を書く。閉じタグの省略やタグの入れ子違反をしない
- エンティティ参照は必要なもの（`&amp;` `&lt;` `&nbsp;` 等）だけに使う。UTF-8 で直接書ける文字はそのまま書く
- 意味的な区切りごとにブロックを空行で分け、大きなブロックにはコメントで見出しを付ける

## CSS

- ID セレクタは使わない。スタイルは class で当てる（ID は具体度が高すぎて上書きが破綻する）
- class 名は「見た目」ではなく「意味・役割」で付ける（`.blue-box` ではなく `.alert`）
- class 名は短く、かつ意味が伝わる長さにする。単語の区切りはハイフン（`.video-id`）
- 型セレクタと class を不必要に併記しない（`ul.example` ではなく `.example`）
- セレクタは必要最小限の具体度にする。祖先を辿るチェーンを長くしない
- `!important` を使わない。使うなら理由をコメントで残す
- ショートハンドプロパティを使う（`padding`, `font`, `background`）
- `0` に単位を付けない（`margin: 0`）
- 小数の先頭の `0` は省略する（`.5em`）
- 16進カラーは小文字で書き、短縮できるものは3桁にする（`#ebc`）
- URL 値の引用符は省略する（`url(images/foo.png)`）
- プロトコル相対 URL（`//example.com/...`）は使わない。`https:` を明示する

## 宣言とルールの並び

- 宣言はアルファベット順に並べる（ベンダープレフィクスは無視して並べる）
- 宣言ごとに1行、末尾に必ずセミコロンを付ける
- ルールセットの間は空行で区切る
- 意味のまとまりごとにセクションコメントを置く

```css
/* Header */
.header-nav {
  border: 1px solid #ebc;
  color: #333;
  margin: 0;
  padding: .5em 1em;
}
```
